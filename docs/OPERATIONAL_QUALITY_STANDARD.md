# Operational Quality Standard

**The binding source of truth is [Value Before Publishing — Mandatory Operating Law](VALUE-BEFORE-PUBLISHING.md), version 1.0.**

All contributors and assistants must read and apply the complete 16-article law before work involving pages, tools, articles, features, or SEO. It governs demand research, competitor review, added value, format choice, accuracy, duplicate-content prevention, tool quality, technical SEO, internal links, pre-publication checks, pull-request evidence, post-publication measurement, continuous improvement, responsibility, and the final publish/no-publish decision.

This document is intentionally a pointer, not a second competing checklist. If older summaries or workflows conflict with the complete law, follow the complete law. Do not publish or merge visitor-facing or SEO work that fails its acceptance gate. Never claim research, tests, access, publication, or results that did not actually occur.

**Commitment:** Value before publishing. Evidence before claims. Quality before scale. Measurement before declaring success.
