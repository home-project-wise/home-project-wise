# Google Search Console Setup

Property: https://home-project-wise.github.io/home-project-wise/

Google generates the exact HTML-tag verification token per Search Console account/property. It must be copied exactly; it cannot be safely invented.

If re-verification is ever required: choose HTML tag in Search Console, copy the exact google-site-verification meta tag, place it in the homepage head, deploy, confirm it appears in the live source, then click Verify.

Sitemap: https://home-project-wise.github.io/home-project-wise/sitemap.xml

In Search Console: Sitemaps -> Add a new sitemap -> sitemap.xml -> Submit.

Official Google guidance: https://support.google.com/webmasters/answer/9008080
