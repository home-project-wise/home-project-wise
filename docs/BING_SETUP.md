# Bing Webmaster Tools Setup

Property: https://home-project-wise.github.io/home-project-wise/

Bing generates the exact BingSiteAuth.xml contents for the account/property. That XML must be copied exactly; it cannot be safely invented.

Preferred path when Google Search Console is already verified: use Bing's Import from Google Search Console option. Otherwise choose XML File authentication, download Bing's generated BingSiteAuth.xml, place that exact file at the deployed site root, then verify.

The repository's current website/BingSiteAuth.xml is only a placeholder and must not be treated as a valid verification file until replaced with Bing's generated XML.
