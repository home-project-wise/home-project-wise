# Bing Webmaster Tools

The repository exposes `sitemap.xml`, `robots.txt` points to it, and the site contains a Bing verification file.

## What can be verified from this repository
- Bing verification file is present in the deployed source.
- The sitemap is generated automatically after publication.
- New article URLs are submitted to IndexNow after the live Pages URL has been verified.

## Account status
The actual Bing Webmaster account state (verified property, crawl/index status, search clicks and impressions) is not exposed by GitHub. Do not claim that Bing has verified or indexed the property unless that is confirmed in Bing Webmaster Tools.

## After account verification
1. Submit `https://home-project-wise.github.io/home-project-wise/sitemap.xml`.
2. Confirm crawl and indexing status.
3. Inspect important new URLs.
4. Fix crawl errors shown by Bing.
