# Bing Webmaster Tools

The site exposes `/sitemap.xml` and `robots.txt` points to it.

## One human step
Add the site in Bing Webmaster Tools and choose XML file verification. Bing supplies the exact `BingSiteAuth.xml` contents. Replace `website/BingSiteAuth.xml` with that exact file and redeploy.

## After verification
1. Submit `https://home-project-wise.github.io/home-project-wise/sitemap.xml`.
2. Confirm crawl/indexing status.
3. Inspect important new URLs.
4. Fix crawl errors shown by Bing.
