How the estimate works

The inner field is the measured length and width after subtracting twice the border width. Field rows and pavers per row are rounded up using the entered paver face dimensions plus the entered joint width. The border area is the total patio area minus the inner field area; its paver-equivalent count is calculated from that area and the repeating paver-plus-joint module area.

Each rectangular section is calculated separately and the quantities are added. This is a quantity estimate, not a cutting or laying plan. Border pavers are full-paver equivalents based on area, not a verified count of individual pieces in a particular border pattern.

What to measure

Patio length and width

Measure each rectangular section separately. Split an L-shape or irregular patio into rectangles that do not overlap.

Paver face dimensions

Enter the actual face length and width, not a nominal product description. Choose the direction in which the long side runs for each section.

Joint and border width

Enter the intended joint width and the border width on each side. Enter 0 when there is no joint or no border; blanks are not treated as zero.

Limits of this calculator

The tool does not calculate base depth, excavation, bedding sand, sub-base, compaction, drainage, slope, retaining walls, load capacity, accessibility, permits or code compliance. It does not recommend a paving pattern or confirm that the ground preparation is suitable. Follow the product instructions and obtain professional advice for site or structural questions.

Common questions

Does the result include extra pavers for breakage?

No. There is no hidden waste or breakage percentage. The result is the calculated quantity only; decide any extra allowance separately using your project and supplier guidance.

Can I enter an L-shaped patio?

Yes. Add separate rectangles that cover the measured area without overlapping. Each section is rounded separately, and offcuts are not reused between sections.

Does it design the border pattern?

No. The border count is an area-based paver equivalent using the same paver size. A contrasting border product or cut layout needs its own measured product and layout plan.
