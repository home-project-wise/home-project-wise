Fence Quantity Calculator

Measure each straight part between post-centre positions. Enter the post spacing you have chosen and each gate's post-centre positions. The calculator counts spans and post positions from those measurements; it does not choose a fence system or spacing for you.

Your fence measurements

Use the same unit for run lengths, gate positions and widths, spacing, panel width and piece length. Measure run ends, spacing and gate positions from post centre to post centre. A gate width here means the distance between the two gate-post centres, not the gate leaf width or clear opening; do not infer it from a gate label. No spacing or unit is preselected.

Optional panel quantity

If entered, panels are estimated by rounding each uninterrupted fenced segment up separately by this width. This is a coverage estimate only; it does not check whether fixed-width panels can be trimmed or fit your post layout.

Shared corners between runs

For one run, leave this blank. For multiple runs, enter the number of simple two-run shared corners; each removes one duplicate post from the total. Branching / three-way junctions are not modelled.

Optional repeated rails or boards

The count appears only when both values are entered. The tool does not choose a rail count, board layout or stock length.

How the count works

Each uninterrupted straight fence segment is divided into the smallest whole number of spans that does not exceed your chosen maximum post spacing. The segment length is then divided evenly across those spans. Each segment's two ends count as posts; gate openings split a run and contribute a post position at each edge. Shared corners between two runs are deducted once only when you enter their count.

Runs are measured separately and rounded separately. Gate position is measured from the start of its straight run to the first gate-post centre; enter the distance between the two gate-post centres. This is not the gate leaf width or clear opening. If you only know the clear opening, the post dimensions and hardware needed to derive centre spacing are not supplied, so do not guess. Gate openings are subtracted from net fence length, but their edge posts remain in the count.

This tool gives quantities from the measurements and spacing you enter. It is not a fence design or installation recommendation. It does not assess post dimensions, foundations, concrete, fence height, wind, frost, property boundaries, easements, utilities, permits, materials, slope, retaining walls or code compliance. Check actual product fit and the site layout separately.
