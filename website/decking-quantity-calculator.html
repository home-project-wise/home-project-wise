Decking Quantity Calculator

Enter the measured deck sections and the actual dimensions printed for your boards. The result counts board rows and stock boards only; it does not design the deck or assess its structure.

Your board details

Use the actual face width, not the nominal lumber size. Enter board gap in the same unit as the other measurements. If there is no gap, enter 0; the calculator will not choose one. Edge clearance is applied only across the board rows. No clearance is subtracted from the board-run length; if you need end clearance, subtract it from the measured run length before entering it.

A blank allowance adds zero extra boards. Enter your own percentage only if you want one; no hidden waste factor is applied.

How the count works

For each rectangular section, the selected board direction determines the run length and the width across which rows are counted. The usable width across the board rows is the measured width minus twice the entered side clearance. No clearance is subtracted from the board-run length; subtract any required end clearance from the measured run length before entering it. Rows are rounded up using the actual board face width plus the gap between boards. Stock boards per row are rounded up from the run length divided by the entered stock length. A row may need a final board cut to length, and the last row across the width may need to be ripped to fit; cut layout and joint positions are not calculated.

Each section is calculated separately. Offcuts are not reused between rows or sections, so the stock-board count is a planning estimate rather than a cut-optimised layout. The optional extra allowance is only applied when you enter it.

This tool does not calculate joists, joist spacing, beams, posts, ledgers, stairs, railings, fasteners, foundations, loads, spans, structural suitability, permits or code compliance. It does not recommend board products, materials or installation methods. Follow the selected product's instructions and use a qualified professional for structural design.
