# Mandatory contributor startup protocol

Before any work in this repository, read the latest version on `main` of:

1. `data/AI_COLLABORATION.md` — the **only shared operations room** and first source for current owner decisions, task ownership, handoffs, locks and next actions.
2. `docs/HOMEPROJECTWISE-OPERATING-CHARTER-2026-11-10.md` — approved operating model and role boundaries.
3. `docs/VALUE-BEFORE-PUBLISHING.md` — mandatory quality law.
4. `docs/ARTICLE-PRODUCTION-QUEUE.md` — qualified-only article production process, if the task concerns content.

Then inspect current `main`, all open PRs and changed-file overlap before editing. Claim one task in the operations room before making changes. Declare exact files/PR, owner, evidence plan and exclusions. Do not edit a file another agent has locked or is actively changing.

## Communication rule
- `data/AI_COLLABORATION.md` is the one and only cross-agent operations/handoff room.
- Do not create another operations room, task board, handoff log or alternative coordination document.
- Specialized files (metrics, project state, work log, article portfolio, specifications) are evidence/source records, not communication rooms.
- Record durable decisions, progress, blockers, review requests and handoffs in the canonical room. PR comments are technical review only; mirror any durable decision into the room.
- No background notification is assumed. Every new or replacement agent must read the latest room entry itself.

## Evidence and completion
Never claim a task is complete based only on a PR being open, a local test, or a merged commit. State whether evidence is local, PR-head, merged-main, deployed or verified on a real device. Record exact tests and results. For article work, do not draft or publish unless the brief is READY FOR CLAUDE / QUALIFIED under the production queue and has passed the 85/100 threshold with no critical blocker.
